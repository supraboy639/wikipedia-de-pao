# La Wikipedia de Pao

App de Android con las noticias de Pao en Rivals (Roblox).

## Cómo instalarla
1. Entrá a **Releases** en este repositorio.
2. Descargá `WikipediaDePao.apk` desde el celular.
3. Abrilo y, si Android lo pide, permití instalar apps de orígenes desconocidos.

Cada vez que se sube un cambio a `main`, GitHub Actions compila un APK nuevo y lo publica en Releases.

Las noticias se editan en `app/src/main/assets/index.html`.
